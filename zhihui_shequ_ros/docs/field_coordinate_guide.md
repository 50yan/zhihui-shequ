# 智慧社区场地坐标说明

本文件对应 `src/zhihui_shequ_sim/worlds/smart_community.world`。

## 你应该怎么看坐标

不要只看 `pose` 里的中心点。更直观的看法是 XOY 平面投影：

- 横线：看“中心线从哪个点到哪个点”。
- 竖线：看“中心线从哪个点到哪个点”。
- 矩形：看“左下角到右上角”。
- `pose=(x,y)` 是中心点，不是端点。
- `size=长x宽` 决定它从中心点向两边延伸多少。

例子：

```text
outer_top: pose=(0.00,4.55), size=9.10x0.06
中心线：(-4.55,4.55) 到 (4.55,4.55)
占地矩形：左下(-4.55,4.52) 到 右上(4.55,4.58)
```

## 更直观的改法

1. 打开 `docs/field_coordinate_editor.html`。
2. 看右侧表格的“XOY 投影”。
3. 找到对象名，例如 `outer_top`。
4. 到 `smart_community.world` 搜索这个对象名。
5. 改 `<pose>x y z ...</pose>` 的前两个数字。

如果你要我改，可以直接说：“把 outer_top 往下移 0.5 米”或“把 people_area_1_board 移到 (-2.0, 2.0)”。
